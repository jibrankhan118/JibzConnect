# JibzConnect

A full-stack real-time communication platform with messaging, channels, voice/video calling, notifications, and AI assistance.

## Features

- Real-time messaging
- Direct messaging between users
- Channel creation and management
- Channel members and admin roles
- Add/remove channel members
- Promote/demote channel members
- Voice and video calling using WebRTC
- Online/offline presence
- Typing indicators
- Message reactions
- Real-time notifications
- AI-powered chat assistance
- Authentication and authorization
- REST APIs
- Real-time communication using Socket.IO

## Technologies

### Frontend
- React.js
- JavaScript
- CSS
- Socket.IO Client
- WebRTC

### Backend
- Node.js
- Express.js
- Socket.IO
- Sequelize
- PostgreSQL
- JWT Authentication

### AI
- Google Gemini API
